# 🌎 Quiz de Bandeiras

Aplicativo de quiz desenvolvido no **Android Studio**, com o objetivo de testar os conhecimentos dos usuários sobre as bandeiras de diferentes países.

O aplicativo apresenta uma sequência de **10 perguntas**, nas quais o jogador deve identificar corretamente a bandeira apresentada. Ao final, é exibido um ranking com o desempenho obtido durante o teste.

## 📱 Sobre o Projeto

O **Quiz de Bandeiras** foi desenvolvido como um projeto acadêmico para a disciplina de **Programação para Dispositivos Móveis**.

O aplicativo possui uma interface simples e intuitiva, permitindo que o usuário inicie o teste, responda às perguntas e visualize seu resultado ao final.

## 🎮 Funcionalidades

* 🏠 **Tela Inicial**

  * Foto dos integrantes da dupla;
  * Nome dos integrantes;
  * RGM dos integrantes;
  * Botão **Iniciar Teste**;
  * Botão **Sair**.

* 🌎 **Quiz**

  * 10 telas de perguntas;
  * Apresentação de diferentes bandeiras;
  * Alternativas para identificação do país;
  * Navegação entre as perguntas.

* 🏆 **Tela Final / Ranking**

  * Quantidade de questões acertadas;
  * Desempenho do jogador;
  * Pontuação obtida;
  * Posição no ranking.

## 🖥️ Estrutura das Telas

### 1. Tela Inicial

Apresenta as informações dos integrantes da dupla, juntamente com os botões para iniciar o teste ou sair do aplicativo.

### 2. Telas do Quiz

O usuário responde a **10 perguntas** relacionadas às bandeiras de diferentes países.

Cada pergunta apresenta uma bandeira e alternativas para que o jogador escolha a resposta correta.

### 3. Tela de Ranking

Após responder todas as perguntas, o usuário é direcionado para a tela final, onde pode visualizar seu resultado e sua posição no ranking.

## 🚀 Como Executar o Projeto

1. Faça o clone deste repositório.
2. Abra o projeto no **Android Studio**.
3. Aguarde a sincronização do Gradle.
4. Conecte um dispositivo Android ou utilize um emulador.
5. Execute o aplicativo pelo botão **Run ▶️**.
